# Downstream use

Downstreams may reuse the reproducible CachyOS composition and decentralized
distribution design under the repository licenses. Use a distinct name and
artwork unless separately authorized to use LuigiOS marks.

Preserve security boundaries when adapting the project: transport does not
authorize installation, trusted roots are not silently replaced, peer sharing
is opt-in, user data is outside the release cache, and source/package pins remain
auditable. Publish source, dependency locks, checksums, provenance, and material
changes with derivative releases.
