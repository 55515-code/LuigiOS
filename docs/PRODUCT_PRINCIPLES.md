# Product principles

1. One coherent desktop. COSMIC is the interface, not an optional mode.
2. Fast by measurement. Prefer CachyOS's maintained kernels, repositories,
   scheduler tooling, and Ananicy rules over local folklore.
3. Reproducible releases. Pin source and content, and reject moving inputs.
4. Safe development. Use containers and memory-safe languages where practical;
   keep compilers and native debugging available where necessary.
5. Security without ceremony. Firewall on, remote login and telemetry off,
   firmware and vulnerability tooling present, developer workflows unobstructed.
6. Recoverable updates. Full transactions and filesystem snapshots are one
   product feature.
7. Professional identity. Branding spans boot through daily applications and
   remains accessible, legible, and restrained.
