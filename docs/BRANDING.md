# Branding

The canonical manifest is `branding/manifest-v2.json`; deployable files are in
`branding/cosmic-rice`. The image embeds the rice and required assets under
`/usr/share/luigios`.

Brand changes must be verified at boot, greeter, COSMIC desktop, launcher,
files, settings, terminal, Code - OSS, peer status, and recovery. Do not replace
familiar third-party icons merely to increase logo frequency. Accessibility and
clear network/privacy status take priority over decorative consistency.
